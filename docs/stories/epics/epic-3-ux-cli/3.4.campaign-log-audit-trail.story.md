## Story

**As a** gestor de tráfego,
**I want** um histórico de todas as campanhas criadas pelo sistema,
**so that** eu tenha controle e possa consultar o que foi criado.

## Acceptance Criteria

1. Cada campanha criada registrada em `~/.meta-ads/campaigns.log` com: timestamp, nome, tipo, orçamento, ID da campanha, status, criativo usado
2. Comando `meta-ads history` exibe últimas 20 campanhas em tabela formatada
3. Comando `meta-ads history --all` exibe histórico completo
4. Filtros: `meta-ads history --type sales`, `meta-ads history --date 09-03-26`
5. Exportar para CSV: `meta-ads history --export csv`
6. Log rotacionado automaticamente a cada 10.000 entradas (arquivo antigo renomeado com data)

### Key Implementation Notes

- **JSON Lines format:** Each line is a valid JSON object, no array wrapper. Parse with `content.split('\n').filter(Boolean).map(JSON.parse)`
- **Log file location:** `~/.meta-ads/campaigns.log` (same dir as `config.yaml`)
- **Fire-and-forget logging:** `logCampaign()` call in orchestrator must NOT block or throw -- wrap in try/catch with `logger.warn()`
- **Date filter format:** `--date DD-MM-YY` matches `createdAt` ISO string by extracting day
- **CSV BOM:** Prepend `\uFEFF` for Excel UTF-8 compatibility
- **Rotation:** Rename existing file, don't copy+truncate (atomic operation)
- **`CampaignLogEntry`** extends `CampaignResult` with `creativeFiles: string[]` and `pageId: string` -- `createdAt` stored as ISO string (not Date) for JSON serialization
- **Table columns:** Nome (campaignName truncated to 30 chars), Tipo (sales/leads), Orcamento (R$ formatted), Status (colorized), Data (DD/MM/YY HH:mm)

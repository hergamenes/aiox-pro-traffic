## Story

**As a** gestor de tráfego,
**I want** autenticar minha conta da Meta no sistema,
**so that** o agente tenha permissão de criar campanhas na minha conta.

## Acceptance Criteria

1. Comando `meta-ads auth setup` inicia fluxo de autenticação OAuth 2.0
2. Sistema abre o navegador para o usuário autorizar o Meta App com permissões `ads_management`, `ads_read`, `pages_read_engagement`
3. Callback local (localhost) captura o authorization code e troca por access token
4. Short-lived token é convertido automaticamente para long-lived token (60 dias)
5. Token armazenado de forma segura no macOS Keychain via `keytar`
6. Comando `meta-ads auth status` mostra status da autenticação (autenticado/expirado/não configurado) e dias restantes do token
7. Sistema alerta quando token está a 7 dias de expirar
8. Mensagens de erro em português para falhas de autenticação

## Dev Notes

### Auth Module Architecture [Source: docs/architecture.md#Components]

The Auth Module (`src/auth/`) is self-contained with three files:
- `oauth-flow.ts` — OAuth 2.0 flow (browser + local callback server)
- `token-manager.ts` — Token retrieval, validation, expiry management
- `keychain.ts` — keytar abstraction (macOS Keychain access)

### OAuth 2.0 Flow [Source: docs/architecture.md#Meta OAuth 2.0 Flow]

Complete flow:
1. CLI opens browser → `facebook.com/dialog/oauth?client_id=X&redirect_uri=http://localhost:3000/callback&scope=ads_management,ads_read,pages_read_engagement`
2. User authorizes → Meta redirects to `localhost:3000/callback?code=ABC`
3. CLI captures code → exchanges for short-lived token
4. CLI exchanges → short-lived → long-lived token (60 days)
5. CLI stores long-lived token in macOS Keychain

### Secrets Management [Source: docs/architecture.md#Security]

| Secret | Storage | keytar Service | keytar Account |
|--------|---------|---------------|----------------|
| Access Token | Keychain | `meta-ads-agent` | `access-token` |
| App Secret | Keychain | `meta-ads-agent` | `app-secret` |
| Token Expiry | Keychain | `meta-ads-agent` | `token-expiry` |

**Rules:** Never hardcode, never in CLI args, never in .env, access only via `keytar`

### Meta API Details [Source: docs/architecture.md#External APIs]

- **API Version:** v21.0
- **Authorization URL:** `https://www.facebook.com/v21.0/dialog/oauth`
- **Token Exchange URL:** `https://graph.facebook.com/v21.0/oauth/access_token`
- **Required Permissions:** `ads_management`, `ads_read`, `pages_read_engagement`

### Error Translation [Source: docs/architecture.md#Error Handling Strategy]

| Meta Error Code | Portuguese Message | Suggested Action |
|----------------|-------------------|-----------------|
| 190 | Token de acesso inválido ou expirado | Execute: `meta-ads auth setup` |
| 10 | Permissão negada | Verifique permissões do Meta App |

### Error Hierarchy [Source: docs/architecture.md#Error Handling Strategy]

```
AppError (base)
├── AuthError
├── ValidationError
├── MetaApiError
└── NetworkError
```

### Coding Standards [Source: docs/architecture.md#Coding Standards]

- **ESM modules:** `"type": "module"` in package.json
- **Strict TypeScript:** `"strict": true` in tsconfig
- **Path aliases:** `@/*` → `src/*` (avoid `../../../` imports)
- **File naming:** kebab-case (`token-manager.ts`)
- **Max 200 lines per file**
- **Async/await everywhere** — never `.then()/.catch()`
- **Pino redact:** Always configure redact for sensitive fields
- **Never log tokens** — use pino.redact for accessToken, appSecret, headers.authorization

### Testing [Source: docs/architecture.md#Test Strategy]

- **Framework:** vitest 3.x
- **Location:** `tests/unit/` mirrors `src/`, `tests/integration/` by flow
- **Naming:** `{module}.test.ts`
- **Pattern:** AAA (Arrange, Act, Assert)
- **Coverage target:** 80%+ overall
- **Mock keytar:** Native module, must be mocked in tests

### Config File Schema [Source: docs/architecture.md#Database Schema]

```yaml
version: 1

  appId: "444555666"
  callbackPort: 3000
```

App ID is stored in config file, App Secret in Keychain (never in plaintext files).

### Important Notes

- **keytar is a native module** — requires compilation on the user's machine. If compilation fails, this is a BLOCKER.
- **App ID and App Secret** are provided by the user from their Meta Developer App at developers.facebook.com
- The HTTP callback server must only listen on localhost (127.0.0.1) for security
- Server timeout of 120 seconds prevents orphaned processes
- **Do NOT install `facebook-nodejs-business-sdk` yet** — it's needed in Story 1.3/2.x, not here

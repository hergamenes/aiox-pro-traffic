## Story

**As a** gestor de tráfego mantendo os squads `traffic-meta` e `traffic-google`,
**I want** que o conteúdo idêntico entre os dois squads seja movido para uma fonte única em `squads/traffic-shared/`,
**so that** qualquer correção ou melhoria nesses arquivos seja feita em um único lugar — sem o risco de os dois squads divergirem silenciosamente.

## Context

Segunda story do **Epic 8 — Traffic Kit: Export dos Squads de Tráfego**. Depende de **Story 8.1 concluída** (squads com CLIs padronizados via PATH).

Hoje existe uma duplicação de ~614 linhas entre os dois squads: templates, checklists e dados que são idênticos (ou com diferenças triviais) em `traffic-meta` e `traffic-google`. Cada um mantém sua própria cópia, criando dois fontes de verdade para o mesmo conteúdo.

Esta story cria `squads/traffic-shared/` com os arquivos comuns e atualiza as referências nos dois squads. O conteúdo específico de plataforma (83% do total — comandos, métricas, integrações específicas do Meta ou Google) permanece intacto em cada squad.

**Constraint crítico:** antes de mover qualquer arquivo, @dev deve fazer diff real entre as versões meta e google. Apenas arquivos comprovadamente idênticos (ou com diferenças triviais a reconciliar) são movidos. Se um arquivo tiver diferenças substantivas de plataforma, ele permanece em cada squad e isso é registrado nesta story.

**O que NÃO faz parte desta story:**
- Unificar os dois squads (decisão deliberada: squads separados)
- Remover perfis de cliente reais (8.3)
- Criar o installer (8.4)

## Acceptance Criteria

1. Criado `squads/traffic-shared/` com `config.yaml` mínimo (name, version, description: "biblioteca de conteúdo compartilhado — não tem agentes próprios") e os seguintes arquivos movidos (condicionado ao diff real confirmar que são idênticos): `templates/campaign-brief.md`, `templates/optimization-log.md`, `checklists/pre-launch.md`, `checklists/optimization-rules.md`, `checklists/report-validation.md`, `data/action-prioritization.md`, `data/utm-conventions.md`, `data/client-profiles/_TEMPLATE.md`.
2. Os dois squads (`traffic-meta`, `traffic-google`) passam a **referenciar** os arquivos em `squads/traffic-shared/` em vez de manter cópias próprias — toda menção dos arquivos listados no AC1 nos agents/tasks/workflows/READMEs aponta para o novo path.
3. Todas as referências em agentes, tasks e workflows que citavam os arquivos movidos apontam para `squads/traffic-shared/...` — zero apontamentos para o path antigo dentro de `squads/traffic-meta/` ou `squads/traffic-google/` para os arquivos migrados.
4. Os dois squads permanecem separados e funcionais: apenas o conteúdo 100% comum é extraído; conteúdo específico de plataforma fica intacto em cada squad.
5. Nenhuma duplicação remanescente dos arquivos listados no AC1 — uma única fonte de verdade em `traffic-shared/`.
6. Se algum dos arquivos candidatos tiver diferenças substantivas de plataforma (identificadas no diff), ele NÃO é movido, permanece em cada squad, e isso é documentado nas Completion Notes do @dev com justificativa.

- **Regra de diff:** usar `diff` ou comparação manual. "Diferença trivial" = texto idêntico com apenas substituição de "Meta Ads" por "Google Ads" no corpo — reconciliável numa versão neutra. "Diferença substantiva" = seções com conteúdo específico de plataforma que não existe no outro (ex.: campos de campanha exclusivos do Meta) — não mover
- **`config.yaml` mínimo para `traffic-shared/`:**
  ```yaml
  name: traffic-shared
  version: "1.0"
  description: "Biblioteca de conteúdo compartilhado entre squads traffic-meta e traffic-google. Não contém agentes próprios."
  ```
- **Referências nos squads:** os agentes e tasks dos squads referenciam arquivos do próprio squad por path relativo (ex.: `../templates/campaign-brief.md` ou path absoluto a partir da raiz do projeto). Ao atualizar, manter o mesmo estilo de referência já usado nos arquivos — apenas trocar o segmento `traffic-meta/` ou `traffic-google/` por `traffic-shared/`
- **Shims em `.claude/commands/`:** verificar se os shims de ativação dos agentes em `.claude/commands/trafficMeta/agents/*.md` e `.claude/commands/trafficGoogle/agents/*.md` têm referências diretas aos arquivos candidatos; se sim, atualizar também
- **Risco E-R2 (do epic):** referência cruzada quebrada após extração. A Task 5 (grep de validação) é o gate que detecta isso antes de declarar Done
- **Não unificar squads:** `squads/traffic-meta/` e `squads/traffic-google/` permanecem como diretórios separados e completos — apenas o conteúdo duplicado é extraído

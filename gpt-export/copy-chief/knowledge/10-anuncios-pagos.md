# Anúncios Pagos (Meta, Instagram e Google)

> Estrutura de copy de anúncio para tráfego pago e conversão: hook nas primeiras linhas, frameworks curtos (PAS, AIDA, BAB), CTA forte e variações para teste A/B.

---

## Regra de ouro do anúncio pago

O leitor está rolando o feed. Seu hook tem **segundos** para parar o scroll. Tudo que importa nas primeiras linhas:
- Pare o scroll (pattern interrupt, promessa específica, pergunta que cutuca a dor).
- Fale com o avatar certo no nível de consciência certo.
- Entregue UM benefício claro e específico.
- Termine com UMA ação clara.

Antes de escrever, defina: **plataforma**, **objetivo** (awareness / tráfego / leads / vendas), **produto** e **público-alvo**.

## Limites de caracteres por plataforma

| Plataforma | Campo | Visível / Máx |
|------------|-------|---------------|
| **Facebook Feed** | Primary text | 125 visível / 500 máx |
| | Headline | 40 |
| | Description | 30 |
| | Aspect ratio | 1:1, 4:5, 16:9 |
| **Instagram Feed** | Caption | 125 visível / 2200 máx (1:1, 4:5) |
| **Instagram Stories** | Texto overlay mínimo, 15s, 9:16 | — |
| **Instagram Reels** | Caption 125, durações 15/30/60/90s, 9:16 | — |
| **Google Search** | 3 headlines de 30 chars + 2 descriptions de 90 chars | — |
| **Google Display** | Headline 30 + description 90 | — |

Validação por plataforma: dentro dos limites? hook prende no tempo certo? CTA claro? visual e copy se complementam?

## Hook nas primeiras linhas — fórmulas prontas

Como só ~125 caracteres aparecem antes do "ver mais", o hook tem que estar na 1ª linha.

**Curiosidade**
- "Ninguém te contou isso sobre {tema}"
- "O erro de R${valor} que você está cometendo"
- "Por que {crença comum} está errado"

**Resultado**
- "{resultado} em {tempo} — sem {objeção}"
- "Como {avatar} conseguiu {resultado}"
- "De {antes} para {depois} em {tempo}"

**Pergunta**
- "Você comete esse erro com {tema}?"
- "Quer {resultado} mesmo {objeção}?"

**História**
- "Eu estava {situação} quando..."
- "Meu cliente {nome} tinha {problema}..."

**Pattern interrupt**
- "ESPERA! Antes de {ação}..."
- "Não {ação} até ver isso"

## Frameworks curtos aplicados a ads

### PAS (Problema – Agitação – Solução) — o mais usado em conversão
```
Problema:  {dor concreta do avatar}
Agitação:  {consequência de não resolver / quanto isso custa}
Solução:   {seu produto como a saída}
CTA:       {ação clara}
```
Ideal para públicos **Conscientes do Problema** (nível 2). Agite a dor antes de oferecer.

### AIDA (Atenção – Interesse – Desejo – Ação)
```
Atenção:   {hook que para o scroll}
Interesse: {benefício principal}
Desejo:    {prova: depoimento, número, demonstração}
Ação:      {CTA}
```
Bom para anúncios um pouco mais longos (Facebook/Instagram feed). Atenção tem que PARAR, não só "chamar".

### BAB (Before – After – Bridge)
```
Before:  {situação atual frustrante}
After:   {resultado desejado, vívido}
Bridge:  {como o produto leva de um ao outro}
```
Excelente para transformações claras e mensuráveis.

## Templates de anúncio

### Facebook / Instagram Feed
```
[HOOK — 1ª linha, antes do "ver mais"]

[Primary text — desenvolve PAS/AIDA/BAB, frases curtas,
quebra de linha frequente para legibilidade no mobile]

Headline (até 40): {benefício + especificidade}
Description (até 30): {reforço ou prova}
Botão CTA: {Saiba mais / Comprar / Enviar mensagem / Cadastrar}

Direção de imagem: {sugestão visual}
Público: {segmentação}
```

### Instagram Stories (9:16, 15s)
```
Slide 1 (1-3s): HOOK — pattern interrupt visual + texto
Slide 2: {benefício / prova}
Slide 3: {CTA — "Arraste para cima" / sticker de link}
Direção visual: {nativo, vertical, sem excesso de texto}
```

### Google Search
```
Headlines (3 × 30 chars):
1. {keyword principal + benefício}
2. {diferencial / prova}
3. {CTA + urgência}

Descriptions (2 × 90 chars):
1. {benefício expandido + CTA}
2. {prova social / garantia + CTA}

Display path: {/caminho-relevante}
Keywords: {termos de busca alvo}
```
No Search o usuário já está procurando (alto nível de consciência): seja direto, use a keyword na headline, foque em benefício + CTA, sem rodeios.

## CTA — chamada para ação

- UMA única ação por anúncio. Não peça duas coisas.
- Verbo no imperativo, próximo passo absurdamente fácil.
- Remova risco: garantia, "sem compromisso", "grátis".
- Urgência genuína (não falsa): quantidade limitada real, prazo, bônus expirando.
- Alinhe o CTA da copy ao botão escolhido (ex.: "Envie WhatsApp" → botão Enviar mensagem).

## Variações para teste A/B

Estrutura de teste recomendada:

| Elemento | Variações |
|----------|-----------|
| Hooks | 3 |
| Headlines | 2–3 |
| CTAs | 2 |
| Imagens/criativos | 2 |

- Orçamento mínimo: R$50–100 por variação.
- Duração do teste: 3–7 dias.
- Teste UM elemento por vez para isolar o que move a métrica.
- Comece testando **hooks** — é o que mais impacta (para o scroll ou não).

## Ajuste por nível de consciência (Schwartz aplicado a ads)

| Nível do público | Abordagem do anúncio |
|------------------|----------------------|
| Inconsciente | Conteúdo/história que revela o problema; topo de funil; copy mais longa |
| Consciente do Problema | PAS — agite a dor, introduza a solução |
| Consciente da Solução | Lidere com o resultado + mecanismo único |
| Consciente do Produto | Diferencial + prova social + comparação |
| Mais Consciente | Direto à oferta, preço, urgência; copy curta |

Erro comum em tráfego pago: rodar anúncio de "oferta com desconto" para público frio (inconsciente). Combine a temperatura do público com o nível da mensagem.

---

## Checklist final antes de subir o anúncio

- O hook está na 1ª linha (antes do corte de "ver mais")?
- Há UM benefício específico e relevante para o avatar?
- A copy segue um framework (PAS / AIDA / BAB), não é um amontoado?
- O CTA é único, claro e com risco removido?
- Está dentro dos limites de caracteres da plataforma?
- Visual e copy se complementam?
- Há 3 variações de hook prontas para testar?

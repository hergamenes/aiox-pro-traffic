# Como publicar o Copy Chief no ChatGPT e compartilhar com clientes

Guia passo a passo. Você NÃO precisa programar nada — é tudo por clique e copiar/colar.

## Antes de começar (pré-requisitos)
- Você precisa de uma conta **ChatGPT Plus** (ou superior) para CRIAR o GPT. *(Seus clientes NÃO precisam pagar para usar — basta uma conta ChatGPT, inclusive a gratuita.)*
- Tenha esta pasta aberta. Você vai usar 3 arquivos:
  - `01-instructions.txt`
  - `02-configuracao.md`
  - `03-knowledge-metodo-copy-chief.md`

## Passo 1 — Abrir o criador de GPT
1. Acesse **chatgpt.com** e faça login.
2. No menu lateral esquerdo, clique em **"GPTs"** (ou **"Explorar GPTs"**).
3. Clique no botão **"+ Criar"** (canto superior direito).
4. Vai abrir uma tela com duas abas no topo: **Create** e **Configure**. Clique em **Configure** (vamos preencher na mão, é mais controlado).

## Passo 2 — Preencher Nome e Descrição
1. Abra o arquivo `02-configuracao.md`.
2. Copie o texto do campo **Name** e cole no campo "Name" do ChatGPT.
3. Copie o texto do campo **Description** e cole no campo "Description".

## Passo 3 — Colar as Instruções (o cérebro do GPT)
1. Abra o arquivo `01-instructions.txt`.
2. Selecione **TODO** o conteúdo (Cmd+A) e copie (Cmd+C).
3. No ChatGPT, cole no campo grande chamado **"Instructions"** (Cmd+V).
   - ⚠️ Tem que caber inteiro. Se aparecer aviso de limite, me avise — o arquivo já foi feito para caber (5.737 de 8.000 caracteres).

## Passo 4 — Conversation starters (sugestões de conversa)
1. No `02-configuracao.md`, há 4 frases em "Conversation starters".
2. No ChatGPT, há 4 caixinhas de "Conversation starters". Cole uma frase em cada.

## Passo 5 — Subir a base de conhecimento
1. No ChatGPT, role até a seção **"Knowledge"**.
2. Clique em **"Upload files"**.
3. Selecione **TODOS** estes arquivos (pode marcar vários de uma vez):
   - O arquivo `03-knowledge-metodo-copy-chief.md` (na pasta principal)
   - Os 12 arquivos dentro da subpasta `knowledge/` (de `01-ofertas...` até `12-pagina-de-venda...`)
   - **Total: 13 arquivos.** O ChatGPT aceita até 20, então cabe tudo.
4. Aguarde o upload terminar (os nomes aparecem na lista). Arquivos maiores podem levar alguns segundos.

> 💡 Dica: quanto mais frameworks na base, mais profundas e específicas ficam as respostas. Esses 12 arquivos são os métodos reais dos lendários (ofertas, VSL, e-mail, lançamento, headlines, anúncios, bullets, página de venda).

## Passo 6 — Capacidades
1. Na seção **"Capabilities"**, marque a caixa **"Web Search"** (ajuda em pesquisa de mercado).
2. As outras (DALL·E, Code Interpreter) podem ficar desmarcadas.

## Passo 7 — Testar antes de publicar
1. Do lado direito da tela há um **Preview** (prévia).
2. Digite um teste, por exemplo: *"Quero um anúncio para o Instagram de um curso de inglês de R$497"*.
3. Confira se ele: (a) faz o diagnóstico, (b) anuncia qual lenda vai usar, (c) entrega a copy, (d) roda o QA do Sugarman.
4. Se algo soar errado, volte ao campo Instructions e ajuste — ou me chame para refinar.

## Passo 8 — Publicar e gerar o link
1. Clique em **"Create"** (ou **"Save"** / **"Update"**) no canto superior direito.
2. Vai aparecer a opção de **compartilhamento**. Escolha:
   - **"Anyone with the link" (Qualquer pessoa com o link)** → é esta que você quer para mandar aos clientes.
   - *(Evite "Only me". "GPT Store" é opcional — publica para o mundo todo pesquisar.)*
3. Clique em **"Copy link"** (Copiar link).
4. Pronto! Esse link é o que você manda para cada cliente — por WhatsApp, e-mail, etc.

## Passo 9 — Como o cliente usa
- O cliente abre o link no navegador OU no app do ChatGPT (celular/desktop).
- Se ele tiver conta ChatGPT (até a gratuita), já começa a conversar com o Copy Chief.
- Não precisa instalar nada nem ter o seu acesso.

---

## Dicas importantes
- **Para atualizar o GPT depois:** volte em GPTs → Meus GPTs → clique no Copy Chief → Edit. O link continua o mesmo após salvar.
- **Privacidade:** não coloque dados sigilosos de um cliente nas Instructions ou Knowledge — esse conteúdo é compartilhado com todos que têm o link. Dados específicos de cada cliente devem ser informados na conversa, não embutidos no GPT.
- **Limite de Knowledge:** o ChatGPT aceita até 20 arquivos. Hoje subimos 1 (o método). Na Fase 2 podemos adicionar os frameworks detalhados de cada copywriter para deixar as respostas ainda mais profundas.
- **Marca:** se mais à frente você quiser uma versão "white-label" (com a marca da sua agência em vez dos nomes dos lendários), dá para gerar a partir dos mesmos arquivos.
